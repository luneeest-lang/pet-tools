# 데스크톱 펫 앱 설계 (Windows)

- 작성일: 2026-11-26
- 상태: 승인됨
- 저장소: `luneeest-lang/pet-tools`

## 1. 무엇을, 왜 만드나

반려동물 사진을 올리면 그 아이를 닮은 도트 캐릭터가 생기고, 그 캐릭터가 Windows 바탕화면에서 지내는 앱이다. 반려동물이 없는 사람도 쓸 수 있도록, 미리 준비된 친구 중에서 골라 시작하는 길도 함께 둔다. 펫은 작업 표시줄 위를 걷고, 쉬고, 하품하고, 잔다. 열린 창의 윗부분에 올라가 앉아 있다가 사뿐히 뛰어내리기도 한다. 사용자는 밥을 주고 쓰다듬으며 가볍게 돌본다.

목적은 수익이다. 첫 버전은 무료로 내서 반응을 보고, 이후 업데이트에서 유료 아이템(펫 추가, 꾸미기 소품, 특별 동작)을 붙여 Steam에 낸다. 그래서 첫 버전은 무료지만, 안쪽 구조는 처음부터 펫 여러 마리와 소품을 담을 수 있게 만든다.

## 2. 목표, 비목표, 반목표

**목표 (첫 버전)**
- 두 가지 시작 방법을 둔다: 사진으로 우리 아이를 닮은 펫 만들기, 준비된 친구 중에서 골라 입양하기.
- 사진에서 털색을 뽑고, 귀·꼬리·무늬·눈 색을 골라 우리 아이를 닮은 도트 펫을 만든다.
- 펫이 바탕화면에서 스스로 지낸다: 걷기, 앉기, 하품, 자기, 창 위로 뛰어오르기, 창에서 뛰어내리기.
- 사용자가 펫을 마우스로 집어 옮기고, 창 위에 올려놓을 수 있다.
- 밥 주기, 쓰다듬기, 재우기로 돌본다. 돌볼수록 친밀도가 쌓이고 새 동작이 열린다.
- Windows 10, 11 (64비트)에서 설치해서 쓸 수 있다.
- 한국어와 영어를 지원한다.

**비목표 (첫 버전에는 넣지 않음)**
- 결제, 유료 아이템, Steam·Microsoft Store 배포
- 펫 여러 마리 동시에 띄우기 (구조만 준비)
- 꾸미기 소품 (구조만 준비)
- AI로 사진을 분석하거나 캐릭터를 생성하는 기능
- 바탕화면 아이콘 위에 앉기
- 소리
- Mac, 리눅스, 휴대폰

**반목표 (기술적으로 돌아가도 이렇게 되면 실패)**
- 펫이 아프거나, 다치거나, 죽거나, 괴로워하는 모습. 사진 속 실제 아이를 닮은 캐릭터이고, 무지개다리를 건넌 아이를 추모하려는 사용자도 있다. 오래 방치해도 "시무룩하다" 이상으로 가지 않는다. 높은 곳에서 떨어져도 항상 안전하게 착지한다.
- 일을 방해하는 펫. 펫이 없는 부분의 클릭은 반드시 뒤쪽 창으로 통과해야 한다. 펫이 입력 포커스를 빼앗으면 안 된다. 전체 화면 게임이나 영상을 가리면 안 된다.
- 하루 종일 켜 두기 부담스러운 앱. 가만히 있을 때 CPU 사용이 눈에 띄면 안 된다.
- 미완성처럼 보이는 화면. "준비 중", 잠긴 버튼 같은 자리 표시를 사용자에게 보여 주지 않는다.
- 사용자 사진을 밖으로 보내거나 몰래 보관하는 것. 동의 없이 어떤 정보든 밖으로 보내는 것(9.1절의 익명 통계도 동의한 경우에만).

## 3. 만드는 방법 (검토한 방법과 선택)

| 방법 | 장점 | 단점 |
|---|---|---|
| **A. Electron (선택)** | 지금 있는 도트 생성기(`prototype/sprites/pixel-pet.js`)를 그대로 쓴다. 투명 창과 클릭 통과가 데스크톱 펫에 많이 쓰여 검증돼 있다. 가장 빨리 만든다. 나중에 Mac 지원이 쉽다 | 설치 파일이 크고(약 80~100MB) 메모리를 더 쓴다 |
| B. Tauri | 설치 파일이 작고 가볍다. 도트 생성기도 그대로 쓴다 | 펫 모양대로 클릭을 통과시키는 부분을 직접 더 짜야 한다 |
| C. C# 네이티브 | 가장 가볍고 Windows에 잘 맞는다 | 도트 생성기를 다시 써야 하고 Mac 지원이 어렵다 |

A를 고른 이유: 개발자(Claude)는 Windows에서 직접 실행해 볼 수 없고, 동작 확인은 사용자 PC에서 한다. 핵심 기능이 검증된 방식으로 가야 시행착오가 적다. 화면 부분은 웹 기술이라, 반응이 좋아 Steam에 낼 때 B로 옮기는 길이 열려 있다.

## 4. 사용자 흐름

### 4.1 첫 실행
1. 설치 후 실행하면 (익명 통계 동의를 물은 뒤) "어떻게 시작할까요?" 화면이 뜬다.

```
┌ 어떻게 시작할까요? ─────────────────────────────┐
│  ┌──────────────────┐   ┌──────────────────┐    │
│  │  [사진 + 도트 펫] │   │ [도트 펫 3마리]   │    │
│  │ 우리 아이 사진으로 │   │ 새 친구 입양하기  │    │
│  │      만들기       │   │                  │    │
│  │ 사진 속 털색으로   │   │ 준비된 친구 중에서│    │
│  │ 닮은 펫을 만들어요 │   │ 골라서 시작해요   │    │
│  └──────────────────┘   └──────────────────┘    │
└─────────────────────────────────────────────────┘
```

   - **우리 아이 사진으로 만들기** → 4.2절 만들기 창
   - **새 친구 입양하기** → 4.3절 입양 창
2. 펫이 정해지면 그 창이 닫히고 펫이 화면 아래쪽 작업 표시줄 위에 나타난다.
3. 작업 표시줄 오른쪽 알림 영역(트레이)에 앱 아이콘이 생긴다. 이후 모든 메뉴는 여기서 연다.

### 4.2 우리 아이 만들기 창

```
┌ 우리 아이 만들기 ───────────────────────┐
│ [사진]  ← 털을 클릭하세요   [미리보기 펫] │
│                                          │
│ 종  ● 강아지 ○ 고양이                    │
│ 털색 ■ ■ □   귀 [선 귀 ▾]  꼬리 [말린 ▾] │
│ 무늬 [없음 ▾]  눈 색 ■                   │
│ 이름 [______]          [바탕화면에 보내기]│
└──────────────────────────────────────────┘
```

1. 사진을 끌어다 놓거나 파일을 고른다. 사진 없이 바로 꾸며도 된다.
2. 종(강아지, 고양이)을 고른다.
3. "털을 클릭하세요" 안내에 따라 사진에서 **주 털색** 부분을 클릭한다. 흰 털이나 두 번째 털색이 있으면 한 번 더 클릭한다. 클릭한 지점 주변(반지름 약 6픽셀)의 평균색을 쓴다. 배경이 섞이지 않게 하려고 완전 자동 대신 클릭 방식을 쓴다.
4. 고른 색에서 명암 5단계를 자동으로 만든다(5.2절). 색 칸을 눌러 직접 고칠 수도 있다.
5. 귀 모양, 꼬리, 무늬, 눈 색을 고른다. 미리보기 펫이 바로 바뀌며 걷고 앉는다.
6. 이름을 지어 "바탕화면에 보내기"를 누른다.
7. **사진은 저장하지 않는다.** 뽑은 색과 고른 항목만 저장한다. 사진은 PC 밖으로 나가지 않는다.

트레이 메뉴의 "다시 꾸미기"로 이 창을 언제든 다시 열 수 있다(입양한 친구도 마찬가지). 이때 친밀도와 해금 동작은 그대로 남는다.

### 4.3 새 친구 입양하기 창
반려동물이 없는 사람을 위한 길이다. 고르기만 하면 바로 시작할 수 있어야 한다.

```
┌ 새 친구 입양하기 ───────────────────────────────┐
│ [전체] [강아지] [고양이]                         │
│                                                 │
│  (펫)    (펫)    (펫)    (펫)    (펫)    (펫)    │
│  보리    두부    까미    치즈    턱이    하늘    │
│  (펫)    (펫)    (펫)    (펫)    (펫)    (펫)    │
│  ...                                            │
│                                                 │
│ [랜덤으로 만나기]     이름 [보리___]  [입양하기] │
└─────────────────────────────────────────────────┘
```

- 준비된 친구들이 격자로 나오고, 각자 제자리에서 가볍게 움직인다(앉아서 꼬리 흔들기, 눈 깜빡임). 하나를 누르면 커다랗게 걷는 모습을 보여 준다.
- 친구마다 어울리는 이름이 미리 붙어 있고, 입양할 때 바꿀 수 있다.
- **랜덤으로 만나기**: 무작위로 한 친구를 골라 준다. 털색과 무늬를 약간 섞어서, 목록에 없는 새로운 조합이 나오게 한다. 마음에 들 때까지 다시 누를 수 있다.
- 고른 뒤 "조금 바꾸기"를 누르면 4.2절 만들기 창이 사진 없이 열려서 털색, 귀, 꼬리, 무늬를 고칠 수 있다.
- 출시 때 준비된 친구는 **12마리**(강아지 6, 고양이 6)를 목표로 한다. 지금 있는 6종(시바견, 몰티즈, 블랙탄, 치즈 태비, 턱시도, 러시안 블루)에 더해, 5.2절 설정값으로 표현할 수 있는 흔한 아이들을 고른다(예: 웰시코기, 푸들, 비숑 느낌의 흰 강아지, 검은 고양이, 삼색이 느낌의 고양이, 고등어 태비). 구체적인 목록과 색은 만드는 사람이 정하되, 그림 시트로 보여 주고 사용자 확인을 받는다.
- 업데이트에서 유료로 팔 "특별한 친구"가 이 창에 추가될 수 있다(첫 버전에는 없음, 자리 표시도 하지 않음).

### 4.4 트레이 메뉴
- 밥 주기
- 펫 불러오기 (화면 밖에 있거나 안 보일 때 화면 가운데 아래로 데려온다)
- 잠시 숨기기 / 다시 보이기
- 다시 꾸미기
- 설정
- 종료

### 4.5 설정
- 크기: 2배, 3배(기본), 4배 (도트 1칸을 화면 몇 픽셀로 그릴지)
- 창 위에 올라가기: 켜기(기본) / 끄기
- 전체 화면 앱(게임, 영상)이 앞에 있으면 숨기기: 켜기(기본) / 끄기
- Windows 시작 시 자동 실행: 켜기(기본) / 끄기
- 언어: 한국어 / English (처음에는 Windows 언어를 따른다)

## 5. 펫 그림

### 5.1 지금 있는 생성기
`prototype/sprites/pixel-pet.js`가 48×40칸 도트를 코드로 그린다. 강아지 3종, 고양이 3종이 있고, 동작은 걷기 6장, 앉기, 눈 깜빡임, 기뻐하기, 하품, 자기 2장이다. 특징:
- 부위(몸, 머리, 귀, 다리, 꼬리)를 도형으로 조합하고 빛 방향에 따라 명암 5단계를 칠한다.
- 겹치는 부위 안쪽 선, 빛 받는 쪽이 연한 외곽선, 반사광, 크고 동그란 눈(5×6칸)
- 걸을 때 머리가 한 박자 늦게 움직이고 귀 끝이 출렁인다.

### 5.2 바꿀 점: 품종 대신 "펫 설정값"으로
지금은 품종 6개가 코드에 고정돼 있다. 이를 다음 설정값으로 그리도록 바꾼다.

```json
{
  "species": "dog",            // dog | cat
  "ears": "pointy",            // dog: pointy | floppy,  cat: cat
  "tail": "curl",              // dog: curl | plume,  cat: long
  "pattern": ["brows", "socks", "belly", "muzzle"],
                               // 고를 수 있는 무늬: muzzle, belly, socks, brows, stripes, tuxedo, blaze
  "fluffy": false,             // 몰티즈처럼 외곽이 몽글몽글한 털
  "colors": { "main": "#e48b3c", "second": "#f3dfc6" },
  "eye": "#8a4f33"
}
```

- 위 값 외에 선택 항목 두 개를 둔다. 저장 파일에도 이 모양 그대로 들어간다.
  - `palette`: 명암 단계별 색을 직접 지정한 값(`F0`~`F4`, `C0`~`C4`, 외곽선, 코, 입, 눈 2색 등). 있으면 자동으로 만든 색 대신 이것을 쓴다.
  - `shape`: 무늬만으로 표현되지 않는 모양 조정값(예: 턱시도의 넓은 흰 입가 `bigMuzzle`, 흰 가슴 `chest`).
- 무늬 `tuxedo`는 프로토타입의 `bigMuzzle` + `chest` + `socks` 조합이고, `blaze`는 이마의 흰 줄(프로토타입 턱시도의 이마 줄)이다.
- 털이 한 가지 색인 아이(몰티즈, 러시안 블루)는 `second`를 비워 둔다. 이때 흰 털 부분도 주 털색 명암을 쓴다.
- 눈 색은 한 가지만 고르고, 눈동자 아래쪽에 쓰는 진한 색은 자동으로 만든다.
- `main`, `second` 한 색에서 명암 5단계를 자동으로 만든다. 지금 손으로 고른 팔레트처럼, 어두운 단계로 갈수록 붉은 보랏빛, 밝은 단계로 갈수록 노르스름하게 색조를 옮긴다. 외곽선 색, 안쪽 선 색도 같은 규칙으로 만든다.
- 지금 있는 6개 품종은 "추천 조합"으로 남겨, 만들기 창에서 한 번에 고를 수 있게 한다. 추천 조합은 지금의 손으로 고른 팔레트를 `palette`로, 턱시도의 모양 조정을 `shape`로 그대로 담는다. 그래서 지금 그림과 똑같이 나와야 한다(검증 기준).
- 사용자가 추천 조합을 고른 뒤 털색을 바꾸면 `palette`를 버리고 자동 명암으로 넘어간다.
- 자동 명암은 6개 추천 조합의 주 털색을 넣었을 때 손으로 고른 팔레트와 "비슷한 느낌"이면 된다. 똑같을 필요는 없다.

### 5.3 새로 필요한 동작
| 동작 | 쓰는 곳 |
|---|---|
| 시무룩 (앉기 변형: 귀가 처지고 눈꼬리가 내려감) | 배부름이나 기분이 낮을 때 |
| 웅크리기 | 뛰기 직전 |
| 공중 (오르는 중 / 내려오는 중) | 뛰어오르기, 뛰어내리기 |
| 착지 (몸이 살짝 눌림 → 원래대로) | 땅이나 창 위에 내려앉을 때 |
| 놀라서 떨어지기 (네 다리를 벌리고 눈이 커짐) | 발밑 창이 사라졌을 때, 높이 떨어질 때 |
| 집혀서 매달리기 (다리가 대롱대롱) | 마우스로 집었을 때 |
| 내려다보기 (창 끝에서 아래를 봄) | 창에서 뛰어내리기 전 |
| 기지개, 뒹굴기, 꼬리 잡기 | 친밀도 해금 동작 (6.3절) |

모든 동작은 강아지와 고양이 둘 다, 모든 설정값 조합에서 자연스럽게 나와야 한다.

### 5.4 나중에 작가 그림으로 바꿀 수 있게
출시 품질을 위해 나중에 도트 작가나 AI 도트 도구로 그림을 바꿀 수 있다. 그래서 앱은 "동작 이름 + 프레임 번호 → 그림" 형태로만 그림을 받아 쓴다. 지금은 생성기가 그림을 만들고, 나중에는 같은 형태의 PNG 그림 묶음으로 바꿔 끼울 수 있어야 한다. 첫 버전에서 PNG 묶음을 읽는 기능까지 만들 필요는 없다.

### 5.5 그리는 방식
펫을 만들거나 다시 꾸밀 때 필요한 모든 동작 프레임을 한 번 그려서 메모리에 담아 둔다(지금 미리보기처럼). 화면에는 크기 설정 배수로 키워서 픽셀이 뭉개지지 않게 그린다. 왼쪽으로 갈 때는 좌우를 뒤집는다.

## 6. 펫의 생활

### 6.1 상태
배부름, 기분은 0~100이다.
- 배부름: 앱이 켜져 있는 동안 10분에 약 4씩 준다. 밥을 주면 +35.
- 기분: 10분에 약 3씩 준다. 쓰다듬으면 +12(같은 쓰다듬기가 3초 안에 반복되면 효과 없음). 밥 먹으면 +5. 자는 동안은 줄지 않는다.
- 앱이 꺼져 있던 동안에도 시간만큼 줄지만, **꺼져 있던 동안에는 40 아래로 내려가지 않는다.** 오랜만에 켰을 때 시무룩한 모습부터 보지 않게 하기 위해서다.
- 배부름이나 기분이 30 아래면 시무룩 상태가 된다. 시무룩할 때는 걷기가 줄고 앉아 있거나 누워 있는 시간이 늘며, 앉을 때 시무룩 그림을 쓴다. 그 이상 나빠지는 일은 없다.
- 밥 주기, 쓰다듬기에 따라 말풍선("냠냠, 맛있어!", "헤헤, 좋아요")과 도트 하트가 뜬다. 밥을 주면 도트 밥그릇이 펫 옆에 잠시 나온다(지금 미리보기와 같음).
- 수치는 화면에 늘 띄우지 않는다. 펫에 마우스를 올리면 이름과 배부름·기분·친밀도가 작은 말풍선으로 나온다.

### 6.2 행동
펫은 아래 상태 중 하나에 있고, 몇 초마다 다음 상태를 무작위로 고른다(시무룩, 시간대에 따라 확률이 달라짐).

| 상태 | 설명 |
|---|---|
| 걷기 | 지금 서 있는 바닥(작업 표시줄 위 또는 창 윗부분)을 따라 걷는다. 바닥 끝에 오면 돌아서거나, 창 위라면 내려다보기로 넘어간다 |
| 앉기 | 꼬리를 흔들며 쉰다. 가끔 눈을 깜빡인다 |
| 하품 | 잠깐 하품한다 |
| 자기 | 누워서 잔다. 밤 시간(사용자 PC 시각 23시~6시)에는 더 자주 잔다 |
| 밥 먹기 | 밥 주기를 받으면 앉아서 먹는다 |
| 뛰어오르기 | 근처 창 윗부분으로 포물선을 그리며 뛰어오른다(6.4절) |
| 뛰어내리기 | 창 끝에서 내려다보다가 아래 바닥으로 뛰어내린다 |
| 떨어지기 | 발밑이 사라지거나 사용자가 놓았을 때 중력으로 떨어진다 |
| 집혀 있기 | 사용자가 마우스로 잡고 있는 동안 |

### 6.3 친밀도와 해금 동작
- 밥 주기 +3, 쓰다듬기 +2(1분에 최대 +6), 그날 처음 돌보면 +5.
- 친밀도가 30, 80, 150에 닿으면 기지개, 뒹굴기, 꼬리 잡기가 차례로 열린다. 열리는 순간 펫 머리 위에 반짝임과 함께 "새 동작: 기지개" 같은 말풍선이 뜨고, 그 동작을 바로 한 번 보여 준다.
- 열린 동작은 쉬는 동안 가끔 나온다.
- 친밀도는 줄지 않는다.

### 6.4 바닥과 창 위
**바닥**은 펫이 설 수 있는 가로 선이다.
- 화면(모니터)마다 작업 영역 맨 아래 선. 작업 표시줄이 아래에 있으면 작업 표시줄 바로 위다. 작업 표시줄이 옆이나 위에 있어도 작업 영역의 아래 끝을 쓴다.
- 열린 창의 윗부분 선. 다음 조건을 모두 갖춘 창만 쓴다: 보이는 상태, 최소화되지 않음, 너비 200픽셀 이상, 다른 창에 가려지지 않은 구간, 화면 맨 위 끝에 붙어 있지 않음(최대화된 창은 제외), 시스템 창이나 펫 자신의 창이 아님. 그림자를 뺀 실제 창 테두리 기준이다.
- 다른 창에 가려진 부분은 바닥에서 빠진다. 가려진 구간으로 걸어가면 그 끝에서 돌아서거나 뛰어내린다.

**창 정보 읽기**: Electron만으로는 다른 앱 창의 위치를 알 수 없으므로 Windows 창 목록과 위치를 읽는 보조 모듈을 둔다. 약 0.2초마다 창 목록을 새로 읽는다. 펫이 창 위에 있으면 그 창만 더 자주(약 0.05초마다) 확인한다.

**창이 움직이거나 사라질 때**
- 펫이 있는 창을 사용자가 옮기면 펫도 같은 만큼 따라 움직인다.
- 창을 닫거나, 최소화하거나, 다른 창이 그 자리를 덮으면, 펫은 놀란 그림으로 바뀌어 떨어진다. 떨어지는 동안 아래에 있는 가장 가까운 바닥에 착지한다.

**뛰어오르기**
- 걷는 중 가끔(약 2~4분에 한 번, 설정에서 끄면 하지 않음) 근처 창 윗부분을 고른다. 가로로 화면 너비의 40% 안, 세로로 화면 높이의 60% 안에 있는 창만 고른다.
- 웅크리기 → 공중(오름) → 공중(내려옴) → 착지 순서로 포물선을 그린다. 착지 지점은 그 창 바닥의 빈 구간이다.

**뛰어내리기**
- 창 위에 올라간 뒤 30초~3분 사이에 한 번 뛰어내린다. 창 끝 쪽으로 걸어가 내려다보기를 잠깐 한 뒤, 웅크리기 → 공중 → 착지.
- 아래 바닥까지 높이가 화면 높이의 절반을 넘으면 놀란 그림으로 떨어지되, 착지 직전에 자세를 바로잡고 착지 그림으로 내려앉는다.

**창 끝에 매달리기** (2026-11-26 추가)
- 창 위에서 내려갈 때가 되면, 뛰어내리는 대신 약 40% 확률로 창 끝에서 미끄러지듯 **앞발을 창 테두리에 걸고 매달린다.** 그림은 정면을 보고 앞발을 걸친 "집혀서 대롱대롱"과 같은 그림을 쓰고, 앞발이 창 윗선에 닿게 놓는다.
- 3~6초 동안 다리를 버둥거리다가, 60%는 웅크리며 다시 창 위로 기어오르고 40%는 아래 바닥으로 폴짝 뛰어내린다.
- 매달린 창을 옮기면 같이 움직이고, 창을 닫거나 최소화하면 떨어져서 안전하게 착지한다.
- 매달린 펫을 마우스로 잡으면 평소처럼 집혀서 대롱대롱이 된다.
- "창 위에 올라가기" 설정을 끄면 매달리기도 하지 않는다.

**창 정보 읽기 방식** (만드는 사람의 판단, 2026-11-26)
- Electron 앱 안에서 Windows 기능을 직접 부르는 라이브러리(koffi)로 창 목록, 창 테두리(그림자 제외), 최소화·숨김 상태를 읽는다. 따로 빌드한 보조 실행 파일은 쓰지 않는다.
- Windows가 주는 좌표는 실제 픽셀이므로, Electron 화면 좌표(DIP)로 바꿔서 쓴다(배율이 다른 모니터 대비).
- 앱 자신의 창(펫 창, 설정 창)은 바닥 후보에서 뺀다.

**물리**
- 떨어질 때 중력 가속도를 쓴다. 공중에서 속도가 너무 빨라지지 않게 상한을 둔다.
- 착지할 때 착지 그림(몸이 눌림)을 0.15초쯤 보여 주고 원래 자세로 돌아온다. 어떤 높이에서 떨어져도 다치는 모습은 없다.

### 6.5 마우스로 집기
- 펫을 누르고 끌면 집혀 있기 그림으로 바뀌고 마우스를 따라온다.
- 놓으면 그 자리에서 떨어진다. 떨어지는 길에 바닥(창 윗부분 포함)이 있으면 거기 착지한다. 그래서 창 위쪽 근처에 놓으면 그 창 위에 올라간다.
- 짧게 클릭만 하면(끌지 않으면) 쓰다듬기로 친다.
- 오른쪽 클릭하면 트레이 메뉴와 같은 메뉴가 펫 옆에 뜬다.
- 화면 밖으로 놓으면 가장 가까운 화면 안쪽으로 떨어진다.

### 6.6 여러 모니터
펫은 한 번에 한 화면에 있다. 걷다가 화면 경계에 닿으면, 옆 화면의 바닥이 이어지는 높이일 때만 넘어간다. 아니면 돌아선다. 사용자가 끌어서 다른 화면으로 옮길 수는 있다.

## 7. 창과 입력 처리 (반목표 지키기)

- 펫 창은 펫 크기보다 조금 큰 투명 창 하나다(말풍선, 하트, 밥그릇이 들어갈 여백 포함). 펫이 움직이면 창을 옮긴다. 화면 전체를 덮는 투명 창은 쓰지 않는다. 다른 앱과 게임 성능에 영향을 줄 수 있어서다.
- 펫 창은 항상 위에 뜨고, 작업 표시줄 목록과 Alt+Tab 목록에 나오지 않는다. 눌러도 다른 앱의 입력 포커스를 빼앗지 않는다.
- 펫 그림이 없는 투명한 부분은 클릭이 뒤쪽 창으로 통과한다. 마우스가 펫의 실제 그림(투명하지 않은 픽셀) 위에 있을 때만 펫이 클릭을 받는다.
- 전체 화면 앱이 앞에 있으면(설정에서 켰을 때) 펫을 숨기고, 그 앱이 내려가면 다시 보인다.
- 가만히 있을 때(앉기, 자기) 화면 갱신을 크게 줄여 CPU를 아낀다. 걷기와 점프 때만 부드럽게 갱신한다.

## 8. 저장

사용자 데이터 폴더에 JSON 파일 하나로 저장한다. 처음부터 펫 여러 마리와 소품을 담을 수 있는 모양으로 만든다.

```json
{
  "version": 1,
  "activePetIds": ["p1"],
  "pets": [{
    "id": "p1",
    "name": "콩이",
    "createdAt": "2026-11-26T10:00:00Z",
    "origin": "photo",          // photo | adopted (입양한 경우 "presetId": "boree" 도 저장)
    "spec": { "species": "dog", "ears": "pointy", "...": "5.2절" },
    "stats": { "full": 70, "mood": 65, "updatedAt": "2026-11-26T10:00:00Z" },
    "affinity": 12,
    "unlocked": ["stretch"],
    "accessories": [],
    "position": { "display": "id", "x": 400, "floor": "ground" }
  }],
  "settings": { "scale": 3, "perchOnWindows": true, "hideOnFullscreen": true, "launchAtStartup": true, "language": "ko" }
}
```

- 상태가 바뀔 때마다 바로 쓰지 않고, 몇 초마다 또는 종료할 때 한 번에 쓴다. 쓰다가 꺼져도 파일이 깨지지 않게 임시 파일에 쓴 뒤 바꿔치기한다.
- `version`으로 나중에 구조가 바뀌어도 옛 파일을 새 모양으로 옮길 수 있게 한다.
- 첫 버전 화면은 펫 1마리만 다룬다. `activePetIds`, `accessories`는 업데이트를 위한 자리이고 화면에는 드러나지 않는다.

## 9. 배포

- Windows 10, 11 (64비트)용 설치 파일(.exe) 하나를 만든다.
- 설치 파일은 GitHub Actions의 Windows 환경에서 빌드한다.
- 첫 버전은 코드 서명을 하지 않는다. 설치할 때 "Windows의 PC 보호" 경고가 뜨므로, 소개 페이지에 "추가 정보 → 실행" 안내를 그림과 함께 둔다.
- 저장소는 공개 저장소다. 자동 업데이트는 이 저장소의 GitHub Releases를 쓰므로 앱에 토큰을 넣을 필요가 없다.
- 소개 페이지는 이 저장소(`pet-tools`)의 GitHub Pages로 만든다. 모아툴(`luneeest-lang.github.io`)과 섞지 않는다. 참고: 지금 계정의 대표 사이트에 moatool.com 도메인이 연결돼 있어서, 따로 도메인을 연결하기 전까지 소개 페이지 주소가 `moatool.com/pet-tools/`로 잡힌다. 홍보를 시작하기 전에 전용 도메인을 연결한다. 펫이 움직이는 미리보기(`prototype/preview`를 다듬은 것)와 다운로드 버튼을 둔다.
- 새 버전이 나오면 앱이 알아서 받아 설치한다(GitHub Releases 기준). 사용자는 다음 실행 때 새 버전을 쓰게 된다.

### 9.1 익명 사용 통계 (동의한 사용자만)

첫 버전의 목적이 "반응 보기"이므로, 실제로 몇 명이 계속 쓰는지와 앱 오류를 알 수 있게 한다.

- 첫 실행 때 만들기 창보다 먼저 한 번 묻는다: "앱을 더 좋게 만들기 위해 익명 사용 정보를 보낼까요? 사진과 펫 정보는 보내지 않습니다." [보내기] [보내지 않기]. 기본 선택은 없다. 설정에서 언제든 바꿀 수 있다.
- 동의한 경우에만 보낸다:
  - 하루 한 번 "앱이 켜져 있음" 신호 (앱 버전, Windows 버전, 언어, 펫 종(강아지/고양이), 친밀도 단계)
  - 몇 가지 사건: 펫 만들기 완료(사진으로 만들었는지, 입양했는지, 입양했다면 어느 친구인지), 다시 꾸미기, 새 동작 해금, 창 위 올라가기 설정 끄기
  - 앱 오류(예외) 기록. 파일 경로 등에서 사용자 이름이 드러나지 않게 지운 뒤 보낸다.
- 보내지 않는 것: 사진, 펫 이름, 색, 창 제목, 다른 앱 정보, IP를 저장하는 식별자. 설치마다 무작위로 만든 ID 하나만 쓴다.
- 통계를 받는 곳은 데스크톱 앱용 개인정보 친화적 분석 서비스나 오류 수집 서비스의 무료 요금제를 쓴다(구체적인 서비스는 만드는 사람이 고른다). 기준: 무료 요금제로 첫 버전 규모를 감당할 것, 동의 전에는 아무것도 보내지 않게 끌 수 있을 것, 데이터 삭제가 가능할 것.
- 소개 페이지에 개인정보 처리방침을 둔다: 무엇을 보내는지, 왜 보내는지, 끄는 방법, 문의 연락처.
- 첫 확인 대상 숫자: 하루에 켜진 설치 수, 설치 7일 뒤에도 켜는 비율, 오류가 난 설치 비율.

## 10. 확인 방법

- **자동 테스트(클라우드에서 실행)**: 상태 수치 계산, 친밀도와 해금, 꺼져 있던 동안의 수치 감소, 바닥 계산(창 목록 → 가려진 구간을 뺀 바닥 선), 점프와 낙하 물리, 저장 파일 읽기·쓰기·버전 옮기기, 색 → 명암 5단계 만들기, 설정값 → 그림 생성.
- **그림 확인**: 모든 동작 × 강아지·고양이 × 추천 조합을 한 장에 그린 시트를 만들어 눈으로 본다(지금 프로토타입과 같은 방식). 6개 추천 조합이 지금 그림과 거의 같은지 확인한다.
- **사용자 PC에서 확인하는 방식**: 사용자는 개발 도구를 설치하지 않고, GitHub Actions가 만든 설치 파일만 받아서 설치한다(만드는 사람의 판단). 그래서 개발 중에도 확인할 때마다 시험용 설치 파일을 빌드해 올린다. 앱에는 처음부터 **진단 모드**를 넣는다: 트레이 메뉴에서 켜면 펫이 인식한 바닥 선과 창 테두리를 화면에 표시하고, 로그 파일을 바탕화면에 내보낸다. 사용자는 문제가 생기면 화면 캡처와 로그 파일을 보내 준다. 창 정보를 읽는 보조 모듈은 따로 빌드한 실행 파일보다 앱 안에 함께 들어가는 방식을 우선한다(백신 오탐과 따로 업데이트할 부담을 줄이기 위해).
- **사용자 PC 확인**: Windows에서만 확인되는 항목(투명 창, 클릭 통과, 포커스, 창 위 올라가기, 창 이동·최소화·닫기 때 반응, 전체 화면 숨기기, 여러 모니터, 자동 실행)은 단계별 체크리스트를 만들어 사용자가 직접 확인한다. 체크리스트는 한 번에 몇 분 안에 끝나게 짧게 나눈다.

## 11. 만드는 사람에게 맡기는 것

- 프로젝트 폴더 구조, 화면 코드의 라이브러리 선택(쓰지 않아도 됨), 테스트 도구
- 창 정보를 읽는 보조 모듈의 구현 방식(예: Node에서 Windows 기능을 직접 부르는 라이브러리, 또는 작은 보조 프로그램)
- 펫 창의 정확한 크기와 여백, 화면 갱신 주기
- 무작위 행동의 확률과 시간 값(6장의 숫자는 시작값이며, 자연스러워 보이게 조정해도 된다)
- 말풍선 문구 세부 (한국어, 영어)
- 트레이 아이콘과 앱 아이콘 그림 (펫 도트를 활용)
- 만들기 창과 설정 창의 세부 디자인 (4.2절의 배치를 따른다)
