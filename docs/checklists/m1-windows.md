# 1단계 확인 체크리스트 (Windows)

문제가 보이면 **화면 캡처**와 **로그 파일**을 보내 주세요. 로그 파일은 펫을 오른쪽 클릭 → "진단 모드 켜기" → 다시 오른쪽 클릭 → "로그 내보내기"를 누르면 바탕화면에 생깁니다.

각 묶음은 5분 안에 끝납니다. 항목마다 "이렇게 하면 → 이렇게 보여야 함"입니다. 결과는 ✅ / ❌ 로 표시해서 보내 주세요.

## 설치 파일 받기

1. GitHub 저장소 `luneeest-lang/pet-tools` → 위쪽 **Actions** 탭 → **Build Windows installer** → 가장 위(최신) 실행을 누릅니다.
2. 아래쪽 **Artifacts**의 `PetTools-Setup`을 눌러 zip 파일을 받고 압축을 풉니다.

## 묶음 A: 설치와 첫 실행

1. `PetTools-Setup-…exe` 실행 → "Windows의 PC 보호" 창에서 **추가 정보 → 실행** → 설치를 마치면 펫(시바견 "보리")이 작업 표시줄 위에 나타남
2. 작업 표시줄 오른쪽 알림 영역(^ 안쪽)에 펫 얼굴 아이콘이 있음
3. 작업 표시줄 앱 목록과 Alt+Tab 목록에 펫이 **나오지 않음**
4. 1~2분 지켜보기 → 펫이 걷고, 앉고, 가끔 하품하거나 잠

## 묶음 B: 일을 방해하지 않는지

5. 펫 바로 옆 빈 곳(투명한 부분)을 클릭 → 펫 뒤에 있는 창이나 바탕화면이 클릭됨
6. 메모장에 글을 쓰다가 펫을 한 번 클릭 → 메모장 커서가 그대로 있고 계속 타이핑됨
7. 펫이 다른 창 위에 겹쳐 있을 때 그 창을 클릭 → 펫이 창 뒤로 숨지 않고 그대로 보임

## 묶음 C: 돌보기와 옮기기

8. 펫을 짧게 클릭 → 하트와 "헤헤, 좋아요" 말풍선
9. 펫 위에 마우스를 1초쯤 올려 두기 → 이름·배부름·기분·친밀도 말풍선
10. 펫을 오른쪽 클릭 → 메뉴가 뜸 → "밥 주기" → 밥그릇과 "냠냠, 맛있어!"
11. 펫을 끌어서 화면 위쪽에서 놓기 → 끄는 동안 앞발을 걸고 대롱대롱 → 놓으면 떨어져서 작업 표시줄 위에 착지
12. 펫을 화면 밖(왼쪽 위 모서리 너머)으로 끌어 놓기 → 화면 안으로 돌아와 착지
13. 트레이 아이콘 → "잠시 숨기기" → 펫이 사라짐 → 다시 "다시 보이기" → 나타남

## 묶음 D: 설정과 저장

14. 트레이 아이콘 → "설정" → 크기 "크게 (4배)" → 펫이 바로 커지고 작업 표시줄 위에 서 있음
15. 설정 → 언어 English → 메뉴와 말풍선이 영어로 바뀜 (확인 후 한국어로 되돌리기)
16. 트레이 → "종료" → 다시 실행 → 펫 위치와 상태가 이어짐
17. 작업 표시줄을 화면 왼쪽이나 위쪽으로 옮기기(작업 표시줄 설정) → 펫이 화면 아래 끝에 서 있음 *(Windows 11은 작업 표시줄 위치를 바꿀 수 없으면 건너뛰기)*
18. PC 다시 시작 → 로그인하면 펫이 자동으로 나타남

## 묶음 E: 여러 모니터 (모니터가 2대일 때만)

19. 펫을 다른 모니터로 끌어 놓기 → 그 모니터 작업 표시줄 위에 착지
20. 두 모니터의 작업 표시줄 높이가 같으면, 펫이 걷다가 경계를 넘어 옆 모니터로 감

## 묶음 F: 컴퓨터 부담

21. 펫이 앉아 있거나 자는 동안 작업 관리자(Ctrl+Shift+Esc) → "Pet Tools" CPU 사용률이 1% 안팎
22. 진단 모드 켜기 → 펫 발밑에 빨간 선(바닥)이 보임 → 로그 내보내기 → 바탕화면에 `pet-tools-log-….txt` 생김
