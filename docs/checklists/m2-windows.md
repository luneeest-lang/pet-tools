# 2단계 확인 체크리스트 (Windows) — 창 위 올라가기·뛰어내리기·매달리기

문제가 보이면 **화면 캡처**와 **로그 파일**을 보내 주세요. 펫 오른쪽 클릭 → "진단 모드 켜기"를 먼저 켜 두면, 펫이 알아본 창 바닥 목록이 로그에 함께 남습니다. 다 본 뒤 "로그 내보내기"를 누르면 바탕화면에 파일이 생깁니다.

결과는 항목마다 ✅ / ❌ 로 표시해서 보내 주세요.

## 묶음 A: 창 위에 올려놓기

1. 메모장을 화면 가운데쯤 띄우기 → 펫을 끌어서 메모장 제목 표시줄 바로 위에서 놓기 → 메모장 윗변 위에 착지해서 그 위를 걸어 다님
2. 파일 탐색기 창으로도 똑같이 → 탐색기 윗변 위에 착지
3. 펫이 올라간 메모장 창을 제목 표시줄로 잡고 이리저리 옮기기 → 펫이 창과 같이 움직임
4. 메모장을 최대화 → 펫이 놀라서 떨어지고 작업 표시줄 위에 착지
5. 다시 메모장 위에 올리고 메모장 닫기(X) → 펫이 떨어져서 착지
6. 다시 올리고 메모장 최소화 → 펫이 떨어져서 착지
7. 펫이 메모장 위에 있을 때 다른 창(탐색기)을 그 위로 덮기 → 펫이 떨어지거나, 덮이지 않은 쪽에 남음

## 묶음 B: 스스로 노는 모습 (창 몇 개 띄워 두고 10분쯤 지켜보기)

8. 작업 표시줄 위를 걷다가 근처 창 위로 웅크렸다가 폴짝 뛰어오름
9. 창 위에서 시간이 지나면 끝으로 걸어가 아래를 내려다봄
10. 내려다본 뒤 아래로 폴짝 뛰어내리거나, 창 끝에 앞발을 걸고 매달림
11. 매달려서 버둥거린 뒤 다시 기어오르거나 뛰어내림
12. 매달린 펫을 마우스로 잡아서 옮길 수 있음
13. 화면 위쪽에 있는 창에서 뛰어내릴 때는 놀란 표정으로 떨어지지만 착지는 안전함

## 묶음 C: 설정과 전체 화면

14. 설정 → "열린 창 위에 올라가기" 끄기 → 창 위에 놓아도 작업 표시줄로 떨어지고, 스스로 뛰어오르지 않음 (확인 후 다시 켜기)
15. 유튜브 영상을 전체 화면으로 → 펫이 사라짐 → 전체 화면을 나가면 다시 나타남
16. 설정 → "전체 화면일 때 숨기기" 끄기 → 전체 화면에서도 펫이 보임 (확인 후 다시 켜기)
17. 작업 표시줄을 눌러 바탕화면만 보이게 해도 펫이 숨지 않음

## 묶음 D: 모니터 2대 (있을 때만)

18. 두 모니터의 배율(디스플레이 설정 → 배율)이 다르면, 각 모니터의 창 위에 펫을 올려 봄 → 펫이 창 윗변에 딱 맞게 섬
19. 창을 다른 모니터로 옮기면 펫도 같이 이동함

## 묶음 E: 컴퓨터 부담

20. 창 몇 개를 띄워 두고 펫이 쉬는 동안 작업 관리자 → "Pet Tools" CPU 사용률이 1~2% 안팎
